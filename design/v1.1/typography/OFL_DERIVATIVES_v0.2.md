# VICENSÆ TYPEFACES v0.2 · OFL Derivatives

Five functional families: **UI, Text, Display, Mono, Canon**, each in Light (300), Regular (400), Bold (700).

- UI — Noto Sans, advance scale 1.015, tracking +8 font units
- Text — Noto Sans, advance scale 1.045, tracking +16
- Display — Noto Serif, advance scale 0.95, tracking +4
- Mono — Noto Sans Mono, original monospaced advances
- Canon — Noto Serif, advance scale 1.08, tracking +14

Each face was generated locally in TTF and WOFF2 (30 binaries total) and bundled as `VICENSAE_TYPEFACES_OFL_v0.2.zip` in the conversation.

**Legal provenance:** modified derivatives of Google Noto fonts, SIL Open Font License 1.1. No claim of original glyph outlines. Upstream Noto copyright and license notices must accompany redistribution; validate Reserved Font Names before official release.

**Publication status:** documentation only in this GitHub branch; **binary files have not been committed**. Do not mistake this PR for complete font delivery.

**Quality:** spacing and visual QA pending; this is not the approved master brand font.
