# VICENSÆ Original Typeface · Genesis v0.1

**Status: EXPERIMENTAL TYPEFACE — NOT BRAND MASTER.**

Original geometric glyph skeletons were authored for this prototype (not extracted from Inter, Raleway, or IBM Plex). The four locally generated static faces are:

| Family | Style | Formats |
|---|---|---|
| VICENSAE UI | Regular | TTF, WOFF2 |
| VICENSAE UI | Bold | TTF, WOFF2 |
| VICENSAE Display | Regular | TTF, WOFF2 |
| VICENSAE Mono | Regular | TTF, WOFF2 |

The fonts have **157 mapped Unicode characters**, including Spanish diacritics, Æ/æ, numbers and basic punctuation. The typeface is an initial geometric engineering proof, **not a polished production-ready font**. It has no advanced kerning, hinting, optical sizes, or complete multilingual coverage. Mono uses fixed advance widths. Display and UI currently use fixed advance widths too, so proportional spacing remains future work.

**Delivery boundary:** The font binaries and generator were created as a downloadable conversation ZIP, but **are not yet committed to this GitHub branch**. The GitHub connector accepts base64 blobs, but this publication step has not been completed. This repository document must not be treated as proof that binary font files exist in GitHub.

The ZIP contains the Python/fontTools/Shapely generator, all eight TTF/WOFF2 binaries, and SHA-256 hashes. The repository's existing design/v1.0 remains unchanged.

Next gates: commit and verify binaries, source generator, license/provenance, specimen, glyph visual regression, naming and font validation, and update CSS @font-face.

**Provenance:** custom geometric outlines. Typeface design, font files and name licensing still require formal approval. No third-party font outline is copied.
