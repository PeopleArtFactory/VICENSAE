# VICENSÆ · Brand & Design System v1.1 RC1

**A working, offline, framework-neutral design system and brand manual.** This is a design candidate, not a finished official brand release or verified fiduciary service.

## Open the specimen
Open `preview/index.html` in a browser. No npm, remote fonts or network are required. The preview includes theme switching, color and type specimens, UI states, a format-only SHA-256 input and an exportable DEMO manifest.

## Contents
- `docs/VICENSAE_BRAND_MANUAL_v1.1-RC1.md`: full Spanish brand/design manual.
- `tokens/core.json`, `tokens/semantic.json`: source token contracts.
- `src/vicensae.css`: scoped CSS components and dark/light themes.
- `preview/index.html`: interactive offline preview.
- `legal/THIRD_PARTY_AND_STATUS.md`: font and license caveats.

## Compatibility and trust
Keep `design/v1.0` unchanged. This v1.1 RC is additive. No font binaries, official voice, institutional proof or authenticated verifier are included. The demo only validates input format and cannot promote a fiduciary state.
