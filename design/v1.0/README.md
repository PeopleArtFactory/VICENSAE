# VICENSAE Design Handbook v1.0

**Always Give and Keep Your Dreams Alive.**

Kit público de estilos y documentación, en formatos abiertos. Incluye CSS, tokens JSON, documentación de integración, una vista previa HTML y plantillas de procedencia para fuentes y voz.

**No contiene archivos de tipografía binaria** `woff2`/`otf`/`ttf`; no existe aún una fuente derivada VICENSÆ verificada. Inter y Raleway son referencias a obtener desde sus distribuidores oficiales, con las condiciones OFL correspondientes.

## Instalación
1. Copiar `src/` al proyecto SvelteKit o integrar su contenido.
2. Importar `components.css` en el layout raíz.
3. Abrir `preview/index.html` en el navegador para probar el panel.
4. Completar las plantillas de procedencia y revisar las licencias antes de distribuir nuevos componentes.
